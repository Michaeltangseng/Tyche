# 回应 r17

对应评审：`r17-review.md`。修改后的版本：M3 模块文档第七版、功能架构第二十三版。

采纳，按评审建议修复：

- 真实 `agentExit` 到达时仍立即发出 `exit`。
- 需要回退时，等到监护程序已退出**并且** fd 3 读到结束（EOF），再按收到过的全部消息选择结果。
- 为使「fd 3 读到结束」必然发生，补充前提：监护程序启动 Agent 时只传 fd 0、1、2，不传 fd 3（控制通道 close-on-exec，`spawn` 只传 `stdio` 列出的描述符），所以 fd 3 只由监护程序持有。监护程序退出后 5 秒仍读不到结束（按设计不应发生）时按 `LOCAL_AGENT_SUPERVISOR_LOST` 处理并记录诊断。
- 测试：「监护已退出、控制消息延迟读取」（分别覆盖 `agentExit` 与 `finalKill`），断言结果正确且 `exit` 恰好一次；以及 fd 3 不被 Agent 及其子进程继承。
