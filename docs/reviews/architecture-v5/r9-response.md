LFS：按评审意见在 B7 写明两个仓库比较的对象不同。影子仓库比较工作目录的原始字节；提交到用户仓库时，由用户仓库自己的属性决定存入内容（换行规范化、LFS 指针），这与用户自己执行 `git add` 的行为一致。前置条件保证的是工作目录此刻与接受版本逐字节、逐模式相同。「曾被强制加入后又超过上限」的已跟踪路径由占位条目覆盖。

测试补充：已跟踪文件变大后快照为占位且对象库没有大对象；占位变化被 diff 报告；LFS 判定；目标文件超限失败；被忽略目标文件提交成功；仅可执行位变化、普通文件换成同内容符号链接时前置条件不满足；重新扫描发现残留时不允许解除保护；解除后各项操作被拒绝、审计已写（D）。
