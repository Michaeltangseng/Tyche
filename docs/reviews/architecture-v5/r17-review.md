1. **[P2] 选择退出结果前，需要先排空控制通道。**
   M3 3.4 规定监护程序退出后，按“收到过哪些消息”选择结果。但操作系统报告进程退出时，fd 3 中的 `agentExit`、`finalKill` 仍可能尚未被 main 读取。此时立即选择回退结果，会把实际成功的调用误判为 `LOCAL_AGENT_SUPERVISOR_LOST`，或误报为清理终止；随后真实消息到达，又受“恰好一次”约束无法更正。

   建议：真实 `agentExit` 到达时仍立即发出 `exit`；需要回退时，则等待监护程序退出且控制通道读到结束，再选择结果。新增“监护已退出、控制消息延迟读取”的测试，同时断言结果正确和事件恰好一次。
